# Exact encoder: portable frozen comparison

Fresh clean-source measurements and validation status are in [RESULTS.md](RESULTS.md).

This package reproduces the original seven-input, three-control standalone experiment. It is self-contained standard-library Python; native RAR is supplied separately and no proprietary binary is included. POSIX permissions/mtime verification requires a POSIX host. This is a local serial protocol, not a broad/native-RAR parity claim.

`vendor/worker.py` is the unchanged mechanical worker, SHA256 `866235a79a0b6e0bde6873efcb17613219a4736c5e74913c26b1611bd880771d`. Its CPU accounting, deterministic role order, task IDs, one warmup, 15 measured pairs, settings and verification are unchanged. `analysis.py` retains the original 5,000-resample paired-median bootstrap functions. Only the path/orchestration layer is portable. `native_smoke.py` retains the twelve-case settings and extraction assertions; any unexpected refusal fails.

Start with a clone containing public revision `d4664689177ad50c5b94906e882e4a36fd3aca8f`. The source recipe uses that revision for both source/log portions and distinct sorted Rust blobs in the 2 MiB input. Every generated byte count/SHA256 must match `corpus.json`; file mode is 0644 and mtime is 1700000000. No input binary is checked into this package.

```sh
B=/absolute/rars/benchmarks/exact-encoder
R=/absolute/rars
python3 "$B/corpus.py" --repository "$R" --output /absolute/corpus
python3 "$B/build_controls.py" --repository "$R" --output /absolute/controls
```

The build recipe makes separate source checkouts of public d466, applies the frozen source-only wide/cyclic patches, verifies every changed source blob, and uses the manifest features. Old reference features live only under `references/`; they are benchmark controls, not production options. Patches do not need unpublished commits or an unmerged PR. `--check-only` validates patch/source reconstruction without compilation. Keep generated controls outside the repository.

Build the candidate from its clean committed source with `cargo build --release --locked -p rars-cli --features experimental-ring-state`, then copy `target/release/rars` to the external candidate path used below. Freeze the compiler/build provenance and use a unique output and label; do not change source or run other CPU workloads during timings. The optional `--control-provenance` accepts the generated `controls.json`; only the three known historical binary hashes may alternatively be supplied without a build receipt. Unknown hashes require the verified source/patch/compiler build receipt; the wrapper binds every control hash to that source basis. Binary hashes are frozen each run; builds across paths/platforms are not claimed bit-identical.

```sh
python3 "$B/benchmark.py" freeze --repository "$R" \
  --candidate /absolute/candidate --current /absolute/controls/current \
  --wide /absolute/controls/wide --cyclic /absolute/controls/cyclic \
  --native-rar /absolute/native/rar --corpus /absolute/corpus/manifest.json \
  --control-provenance /absolute/controls/controls.json \
  --label exact-final --output /absolute/run
python3 /absolute/run/benchmark.py screen --output /absolute/run
python3 /absolute/run/benchmark.py qualify --output /absolute/run
python3 /absolute/run/assess.py /absolute/run/qualification.json > /absolute/run/assessment.json
```

The screen stops after seven current-control cases and requires exact archive hash identity, with both native and candidate integrity/extraction checks. Qualification resumes current, wide and cyclic serially; each retains 300-second screening and 600-second confirmation budgets and a 60-second task deadline. It requires all 15 pairs, deterministic candidate bytes across runs and matching current bytes, and revalidates extraction receipts. Resuming uses the same frozen manifest; failed/incomplete coverage remains explicit.

Assessment exits 0 only if **all five unrounded upper 95% bounds are <=1**: dictionary-distance CPU/current, pressure CPU/current, 2 MiB wall/wide, CPU/wide and RSS/cyclic. Exit 2 means failure. Do not change a seed/label/setting, omit samples or rerun unchanged code to seek a passing interval. Other workloads remain in results; no aggregate hides regressions. Tiny wall times include polling/startup; CPU includes startup. No cold cache eviction is performed.

After timing is finished:

```sh
python3 /absolute/run/benchmark.py smoke --output /absolute/run
python3 /absolute/run/benchmark.py export --output /absolute/run --destination /absolute/public-results.json
python3 "$B/selfcheck.py" --repository "$R"
```

Smoke covers RAR5/4 MiB and RAR7/fractional 3 MiB, levels 1/3, plain/delta-1/solid, with the full 2 MiB payload and both decoders. The export excludes local filesystem paths; retain raw frozen receipts privately. Full project tests remain separate. The self-check verifies exact corpus bytes/metadata, reference source reconstruction, pinned worker and bootstrap boundaries, without building or encoding.
